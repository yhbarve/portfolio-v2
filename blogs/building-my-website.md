Here's a thread describing the best features & hidden pages from my website ([yhbarve.me](http://yhbarve.me)).

---

1. Home Page

The initial 2-column homepage layout was inspired by the incredible portfolio of Brittany Chiang ([brittanychiang.com](https://brittanychiang.com/)).

However, over time, I’ve moved away from that framework and evolved the design to create my own unique identity.

![](https://pbs.twimg.com/media/HJm4TekW8AALw-Q.jpg)

![](https://pbs.twimg.com/media/HJm4VhgWsAEFH6R.jpg)

---

2. Custom Themes

This is my FAVORITE feature. The site comes in 3 unique themes: Neon, Quartz, and Ferrari HP. Each of these has a special place in my life (especially the last one).

It took me a few iterations to make the styling modular so I can add new themes easily.

![](https://pbs.twimg.com/media/HJm5yGcWYAIoGGF.jpg)

![](https://pbs.twimg.com/media/HJm500yW0AQ1BGn.jpg)

![](https://pbs.twimg.com/media/HJm54YxWcAAxzih.jpg)

---

3. Command+K Palette

I first built this feature just to change themes from any page. But I realized I could also add commands to navigate pages, copy my email, and visit my socials.

For even better UX, it also supports keyboard shortcuts! Press Cmd+K from any page to invoke it.

![](https://pbs.twimg.com/media/HJm7CdUWkAIDQc0.jpg)

---

4. Writings / Blog
I built a native blog using Markdown and Contentlayer. It's a feature I've ALWAYS wanted to build! It brings together the ease of writing in Markdown and the awesomeness of HTML.

I've already published quite a few posts, and have a few more in the pipeline.
